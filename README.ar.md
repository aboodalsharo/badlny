# بَدّلني | Badlny

منصة طلابية مستقلة تساعد طلبة جامعة العلوم والتكنولوجيا الأردنية على إيجاد زملاء يرغبون بتبادل الشعب الدراسية.

[الموقع المباشر](https://badlny.netlify.app/) · [English](README.md) · [بنية المشروع](docs/ARCHITECTURE.md) · [الأمان](SECURITY.md)

![واجهة بَدّلني](docs/images/desktop.png)

## الفكرة

الطالب يحدد المادة والشعبة التي معه والشعب المطلوبة. يمكنه البحث بين الطلبات أو إضافة طلبه، ثم التواصل مع زميل مناسب. المطابقة التامة تعني أن كل طالب يمتلك الشعبة التي يريدها الآخر.

الموقع ليس نظام تسجيل رسميًا للجامعة؛ التبديل الفعلي يتبع إجراءات الجامعة، ولا تضمن المطابقة توفر المقعد أو نجاح التبديل.

## المزايا

- واجهة عربية من اليمين لليسار، متجاوبة، بمظهر فاتح وداكن.
- البحث حسب الكلية والتخصص والمادة ورمز المساق ورقم السطر والشعبة.
- كتالوج أكاديمي يضم 1702 مادة و14 كلية/مركزًا في هذه النسخة.
- مطابقة الطلبات المتبادلة، وإضافة طلب دون إنشاء حساب.
- حذف الطلب عبر التحقق من كلمة سر خاصة به على الخادم.
- أرقام التواصل لا تظهر ضمن قائمة الطلبات؛ تظهر عند اختيار التواصل.
- دعم لوحة المفاتيح وتقليل الحركة.

## تجربة محلية آمنة

تحتاج Node.js بإصدار 22.13 أو أحدث وpnpm بإصدار 11.22.0:

```sh
git clone https://github.com/aboodalsharo/badlny.git
cd badlny
pnpm install --frozen-lockfile --ignore-scripts
pnpm preview
```

افتح http://127.0.0.1:4173/. الطلبات هنا محلية في ذاكرة العملية فقط، ولا يوجد اتصال بقاعدة Supabase الإنتاجية. توجد أيضًا تجربة محلية بقاعدة PostgreSQL موضّحة في [دليل التشغيل المحلي](docs/LOCAL-DEVELOPMENT.md).

## الفحوص

```sh
pnpm build
pnpm test
pnpm check:repository
```

الاختبارات تستخدم بيانات وهمية ومحاكاة، ولا تنشئ أو تحذف طلبات حقيقية. فحوص GitHub Actions لا تحتوي أسرارًا ولا تنشر الموقع تلقائيًا.

## حماية الأسرار والبيانات

المستودع يحتوي الكود والكتالوج الأكاديمي فقط، وليس تصديرًا لبيانات الطلبة. لا ترفع مفاتيح الخادم، كلمات السر، ملفات `.env`، مجلدات `.temp` أو النسخ الاحتياطية. الروابط العامة ومسارات API ليست مفاتيح سرية.

لا يوجد ضمان أمان كامل؛ كلمة السر البسيطة قد تُخمن، وحدود المحاولات تقلل الخطر ولا تلغيه. راجع [سياسة الأمان](SECURITY.md).
